# SkyBit OS — Nexus Developer Environment 2.0

A fictional browser-based operating-system showcase built with vanilla HTML, CSS and JavaScript.

## What changed

- Cinematic boot screen with Japanese Matrix-style canvas rain
- Secure-boot HUD, log stream, animated progress bar and skip control
- Glassmorphism desktop with holographic rings, aurora glow and perspective grid
- Modular window manager with drag, resize, minimize, maximize and focus handling
- Start launcher, taskbar, notifications and quick controls
- Dashboard, terminal, file explorer, browser, projects, settings, toolbox, notes and about apps
- LocalStorage persistence for theme and visual preferences
- Responsive mobile layout
- Low-cost canvas particle field with a reduced-motion fallback
- No framework, no build step, static GitHub Pages friendly

## Deploy

Upload the repository contents to the `main` branch and enable GitHub Pages for the repository root.

## Notes

The telemetry shown in Dashboard is synthetic and is not intended to represent real hardware measurements. The Browser app opens external destinations in a new tab rather than embedding arbitrary third-party pages in an iframe.
